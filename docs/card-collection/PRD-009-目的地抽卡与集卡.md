# PRD-009 · 目的地抽卡、打卡与集卡

> 编号：PRD-009 ｜ 版本：v0.1 ｜ 日期：2026-11-04 ｜ 状态：**草稿**

## 1. 背景与目标

现有方案库、出行计划、长按打卡和徽章已经覆盖基本执行流程，但孩子主要是“被带着去”，目的地选择缺少期待感，完成后的经历也缺少可持续回看的收藏载体。

本主题域增加一条轻量游戏化主线：

1. 从适合家庭的候选方案中随机抽出三张目的地卡片；
2. 洗牌后由孩子凭直觉翻开一张，形成对下一次活动的期待；
3. 经家长确认后转为下一次出行，不因抽卡绕过天气、安全与装备判断；
4. 到达目的地并完成打卡后，将卡片收入本家庭的集卡册；
5. 用真实风景、活动要素和收藏记录帮助孩子回看成长，而不是用稀有度、排名或连续签到制造压力。

## 2. 用户与使用边界

- 主要用户：受邀家庭中的孩子，在家长陪同下完成抽卡、翻牌和查看集卡册。
- 关键决策者：家长，负责候选池、出发前确认、到达确认和安全退出。
- 使用范围：自家及 2–5 家受邀朋友，非公开服务。
- 公共方案可以被不同家庭抽中；画像、抽卡记录、出行、打卡与收藏默认按账号隔离。
- 卡片只是方案的选择与呈现方式，不是导航凭证、门票或安全保证。

## 3. 术语

| 术语 | 含义 |
|---|---|
| 候选池 | 当前已审核、未退役，并满足家庭基本画像约束的公共方案集合。 |
| 抽卡组 | 一次抽卡产生的三个互不重复目的地及其打乱后的顺序。 |
| 目的地卡 | 面向孩子展示的卡片，包含真实风景、目的地名称、活动要素与必要安全信息。 |
| 收藏卡 | 已完成有效目的地打卡后进入家庭集卡册的卡片。 |
| 有效打卡 | 归属于当前账号和当次出行、达到到达确认条件且成功持久化的记录。 |

## 4. 核心流程

| 步骤 | 用户动作 | 系统结果 |
|---|---|---|
| 1. 发起抽卡 | 点击“开始抽卡” | 从候选池选择三个不同目的地，生成抽卡组。 |
| 2. 洗牌铺开 | 观看或跳过动画 | 三张卡背打乱顺序并铺开，卡片内容不可提前识别。 |
| 3. 随机翻牌 | 点击任意一张卡背 | 仅该卡翻开，其余卡降低视觉权重；记录所选目的地。 |
| 4. 目的地揭晓 | 查看风景、活动、强度与安全信息 | 用户决定设为下次活动、重新抽卡或退出。 |
| 5. 出发前确认 | 家长确认天气、开放、装备和离线包 | 生成或关联个人 Trip；确认不代表当天必须出发。 |
| 6. 到达打卡 | 到达后由家长确认并长按打卡 | 保存有效打卡，产生收藏资格。 |
| 7. 卡片入册 | 点击“收入集卡册” | 卡片写入当前账号集卡册并展示反馈。 |
| 8. 查看集卡册 | 筛选、查看卡片详情 | 回顾真实完成的目的地、日期与活动内容。 |

## 5. 功能需求

### 5.1 候选池与发起抽卡

| # | 需求 | 状态 |
|---|---|---|
| 5.1.1 | 候选池仅包含已审核、未退役且当前可采用的 Plan；排除信息不完整、存在未处理安全问题的方案。 | 🔨 |
| 5.1.2 | 按当前家庭画像排除明显超出体能、年龄、可接受车程或活动禁忌的方案；无法判断时宁可不进入候选池。 | 🔨 |
| 5.1.3 | 每次抽卡产生三个不同目的地；候选不足三个时明确展示实际数量，不复制卡片凑数。 | ⚠️ 原型按三卡设计，不足场景待实现 |
| 5.1.4 | 候选充足时优先出现尚未收藏的目的地；需要重复目的地时标注“再去一次”，不得伪装为新收藏。 | ⚠️ 原型验证优先未收藏逻辑 |
| 5.1.5 | 抽卡入口说明随机规则和安全边界，不使用“稀有目的地”“必中”等诱导文案。 | ⚠️ 原型已验证 |
| 5.1.6 | 候选为空时展示暂无合适方案及调整画像/等待审核的指引，不能进入空牌堆。 | 🔨 |

## 8. 指标与保护

- 首次抽卡完成率：完成翻牌的抽卡组 / 已发起抽卡组，用于发现流程阻塞，不用于强迫选择。
- 抽卡采用率：翻牌后主动设为下次活动的抽卡组 / 已完成抽卡组；低采用时先检查候选匹配。
- 真实入册率：有效打卡后成功持久化的收藏 / 应入册打卡，目标应接近 100%。
- 回顾价值：家庭主动打开历史卡的次数和访谈反馈，不使用集卡数量评价孩子。
- 保护指标：重大安全事故为 0；跨家庭数据事件为 0；因抽卡/连续记录诱导冒险的反馈为 0。
- 不设抽卡次数、每日签到、卡片稀有度、家庭排行榜或收集速度目标。

## 9. 验收场景

| ID | 场景 | 通过标准 |
|---|---|---|
| V1 | 正常八步链路 | 发起 → 三卡洗牌 → 翻一张 → 揭晓 → 确认 → 打卡 → 入册 → 集卡册均可见且状态一致。 |
| V2 | 随机与去重 | 连续多次抽卡顺序可变化；同组无重复目的地；候选不足时不伪造卡片。 |
| V3 | 翻牌幂等 | 连点、多指或刷新不能使同一抽卡组出现多个有效选择。 |
| V4 | 安全退出 | 天气不适合、准备不足或家长取消时，无惩罚且已有收藏不变。 |
| V5 | 打卡中断 | 长按提前松开、失焦、取消均不打卡；键盘可等效完成。 |
| V6 | 弱网与重试 | 本机记录与服务端确认状态可区分，重试不重复打卡或收藏。 |
| V7 | 账号隔离 | 2–5 家受邀账号只能读取自己的抽卡、Trip、打卡和收藏。 |
| V8 | 重复目的地 | 第二次完成更新 revisit，不产生同账号同 Plan 的重复收藏卡。 |
| V9 | 图片真实性 | 每张图能追溯真实目的地、参考来源和许可；裁切后保留关键地貌与代表景观。 |
| V10 | 图片失败 | 资源缺失时明确提示照片未打开，目的地文字与流程不中断。 |
| V11 | 手机与无障碍 | 窄屏三卡等宽、无横向溢出；减少动态效果和键盘操作可用。 |
| V12 | 主题一致 | 五套方案完成同一用例，内容、顺序、收藏和完成状态不因主题变化。 |

## 明确不做的（边界）

- 不做公开抽卡广场、家庭排名、评论、动态或社交分享。
- 不做付费抽卡、概率稀有度、随机奖励、卡片交易或兑换。
- 不做每日签到、连续打卡奖励、卡片过期或未完成惩罚。
- 不用抽卡结果替代天气、开放状态、体能和安全判断。
- 不做实时 GPS 导航、持续轨迹记录或救援承诺。
- 不将第三方攻略原文、未授权图片、家庭地址、孩子画像或精确轨迹写入可分发卡片。
- 不因增加皮肤而引入公开化、多用户社交或复杂基础设施。
