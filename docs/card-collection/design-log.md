## 共同质量门槛

- 每套从独立 HTML 结构开始，不继承旧主题 CSS，不用“换肤”冒充方案。
- 首屏、洗牌、翻牌、目的地详情、出发准备、到达打卡、入册和集卡册均单独设计。
- 每套有独立的视觉焦点、空间关系、材质、导航和收藏表达，交互结果保持一致。
- 使用真实且可授权的目的地素材；不使用抽象几何图冒充目的地实景。
- 卡面信息完整，文字可读，关键安全信息不受装饰影响。
- 手机无横向溢出；支持键盘、减少动态效果和错误回退。
- 完整流程与刷新收藏均实际浏览器验证。
- 历史原版只归档；贴纸与积木不进入本轮五套方案。
