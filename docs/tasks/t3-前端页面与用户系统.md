# T3 · 前端页面与用户系统

> 状态：🔲 待做 ｜ 依赖：T2

## 范围

### 首页

- Hero：卡通头图 + 标题 + 由 profile 生成的副标题。
- MonthRail：左侧月份时间轴，点击滚动到对应月行。
- MonthRows + PlanCard：按月分组，卡片横滑，归档进底部备用区。
- 安全口诀横幅。
- 成就抽屉：徽章墙、统计条、足迹图，`?panel=badges|footprint` 自动打开。

### 详情页

- Snav：吸顶胶囊导航，滚动高亮当前区块。
- DetailRail：左侧全赛季周时间轴。
- 区块：目标/提示、小勇士任务、行程时间轴（含活动小图）、路线图（自驾+徒步）、装备清单（可勾选+进度条）、安全要点、回顾。
- 打卡：长按打卡 + 徽章解锁动画。
- 多日计划按 `dayNames` 分组渲染。

### 用户系统

- 登录页 / 注册页。
- 用户切换、登出。
- 个人画像查看/编辑（家庭位置、成员、孩子信息、偏好）。

## 验收

- 首页与详情页视觉、交互与原 `site/` 一致。
- 装备/任务勾选状态写入后端，刷新不丢。
- 打卡、徽章解锁流程正确。
- 多用户能各自管理自己的 trips 和状态。
