## 范围

- `web/` 目录：Vite + React 18 + TypeScript 脚手架。
- 路由：`/` 首页、`/plan/:id` 详情页、`/login` 登录页。
- API 客户端：openapi-typescript 从后端 `/openapi.json` 生成类型，封装 fetch client。
- 认证状态：登录/注册 Context，JWT 存储与自动注入请求头。
- 样式：移植 `site/css/style.css` 的设计 token 和基础样式。
- SVG 模块机械移植：`site/js/scenes.js` → `web/src/svg/scenes.ts`，`site/js/maps.js` → `web/src/svg/maps.ts`（算法/视觉不变，补 TS 类型）。
- 公共组件：Layout、MonthRail、PlanCard、ArchiveGrid、SafetyBanner、BadgeDrawer。

## 验收

- `npm run dev` 起服务，首页/详情页/登录页路由可达。
- `npm run build` 类型检查通过。
- `/api/plans` 能拉到数据，认证流程通。
- SVG 移植输出与旧站关键标记一致。
