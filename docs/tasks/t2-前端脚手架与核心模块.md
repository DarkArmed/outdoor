# T2 · 前端脚手架与核心模块

> 状态：✅ 代码完成（PR #4 待合并）｜ 依赖：T1

## 范围

- `web/`：Vite + React 19 + TypeScript，启用严格类型检查。
- 路由骨架：`/`、`/plan/:id`、`/login`；页面内容和业务交互由 T3 实现。
- API 客户端：openapi-typescript 从后端 `/openapi.json` 生成类型，axios 封装请求。
- 认证模块：登录/注册 Context、JWT 存储与注入、恢复会话和退出；登录/注册表单由 T3 实现。
- 样式：移植 `site/css/style.css` 的设计 token 和公共组件基础样式。
- SVG 机械移植：`scenes.ts`、`maps.ts` 保持原算法和视觉，补齐类型；地图通过参数传入路线、路网和计划数据。
- 公共组件：Layout、MonthRail、PlanCard、ArchiveGrid、SafetyBanner、BadgeDrawer。

## 验收边界

本任务验收模块与脚手架代码，不要求完成可用的业务应用。

- `npm run build` 严格类型检查及打包通过。
- 三个路由骨架可直接访问。
- API 模块测试覆盖计划请求、OAuth2 登录编码和 JWT 注入；认证模块测试覆盖注册后登录、恢复、退出和迟到响应。
- SVG 移植输出与旧站一致。
- 公共组件支持复用；抽屉由 props 控制，内容、API 请求和 URL 联动归 T3。

## 完成说明

- 补齐 ArchiveGrid（筛选归档与空状态）、SafetyBanner（原站口诀，可传入规则）、BadgeDrawer（双面板插槽、模态焦点、键盘切换、关闭与焦点恢复）。
- 公共 API 请求和 SWR hooks 使用生成类型，`/trips` 列表对应 `TripOut[]`。私有 hooks 按用户区分缓存，退出后重建会话缓存。
- 地图输入类型见 `web/src/svg/mapTypes.ts`；不依赖旧站全局变量。无路线时保留示意图回退，缺少徒步点位时返回空字符串。
- Vitest：25 个测试通过，其中逐字比较旧站与移植后的场景、自驾、徒步、路网和足迹 SVG。
- Playwright：10 个桌面/移动端测试通过，覆盖路由骨架及公共组件交互；已检查组件截图。
- API 与认证流程使用测试替身验证契约，本次未连接真实后端进行端到端联调。

T3 继续负责首页/详情页组合、登录注册表单、画像/出行管理、清单持久化、打卡与徽章解锁业务。
