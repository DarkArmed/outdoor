# 调研报告（investigation/）

> 存放系统性调研的过程、数据与结论：一次值得归档的实验/排查完成时新增一项。
> **规则：新增调研必须先在本文件索引登记；编号 INV-xxx 三位递增、不回收。**

## 组织规则

- 每项调研一个二级目录：`INV-xxx-主题/`，目录名即编号+主题（参考 PRD/ADR 命名）
- 目录内固定结构：
  - `INV-xxx-主题.md` — 调研报告正文（文档头：`编号 · 版本 · 日期 · 状态`，文末「修订记录」）
  - `scripts/` — 调研中诞生/改造的重要脚本
  - `data/` — 关键数据（汇总表、代表性原始日志）
- 大型原始数据（语料、全量批次日志）仍留在 `corpus/`（gitignore 本地），报告里指路即可，不入库
- 调研结论若沉淀为长期机制，应再写入 `docs/tech/` 对应文档（How），调研目录只作档案
- `scripts/` 内为**归档快照**：脚本路径绑定原始运行位置（`corpus/collection/`、流水线 venv），搬离后不可直接运行，仅供复现参考
