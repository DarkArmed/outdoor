# PRD-005 · 微信小程序客户端

> 编号：PRD-005 ｜ 版本：v1.0 ｜ 日期：2026-10-01 ｜ 状态：**已确认**
> 需求项状态：✅ 已实现（全部需求项，2026-10-01）

## 一、背景与目标

查看计划、核对装备、现场打卡都发生在手机上，而现有 `site/` 与 `web/` 面向桌面浏览器。本主题域新增**微信小程序客户端**，覆盖「出发前 → 路上 → 现场 → 回来后」的移动场景：

1. 微信一键登录，免去注册/记密码；
2. 随时随地浏览本赛季方案库、查看方案详情；
3. 把方案加入「我的出行」，在手机上勾选任务与装备（状态存服务端，换手机不丢）；
4. 现场查看行程、路线与安全要点，长按打卡、解锁徽章。

主要用户是爸爸（规划与执行者），次要用户是同住家人（查看）。

## 二、使用场景（验收视角）

- **2.1 首次使用**：打开小程序 → 登录页点「微信一键登录」→ 自动创建账号并进入计划库。
- **2.2 日常使用**：再次打开小程序免登录，直接进入上次浏览的内容。
- **2.3 了解方案**：在计划库按月份浏览卡片，点开看目标、行程、装备、安全等完整方案内容。
- **2.4 加入出行**：从方案详情底部一键「加入我的出行」（可改出发日期）；新用户也可在「我的出行」空状态一键加入本赛季全部方案。
- **2.5 出发前**：在出行详情逐项勾选装备，进度条实时显示「已准备 N/M 件」，全部勾选后显示庆祝文案；小勇士任务同样可勾选。
- **2.6 路上/现场**：查看行程时间轴与原生地图上的真实路线（驾车线 + 徒步途径点），随时翻阅安全要点。
- **2.7 结束后**：长按 2 秒打卡 → 出行变为已完成 → 弹出徽章庆祝；任务全部完成时徽章展示为满星版；满足里程碑规则时一并解锁并展示。
- **2.8 我的**：查看昵称、统计（已冒险次数 / 徒步 km / 露营晚数）、徽章墙与家庭画像摘要；可退出登录。
- **2.9 多设备一致**：同一微信账号换手机登录，勾选与打卡状态一致。

## 三、功能需求

### 3.1 全局

- **3.1.1** 启动时存在有效登录态则免登录直接进入；登录态失效时先尝试静默重新登录（无感换 code），仍失败才进入登录页。
- **3.1.2** 底部三个 Tab：**计划库**、**我的出行**、**我的**。
- **3.1.3** 视觉沿用既有纸系卡通风格：奶油纸底色、白色圆角卡片、主题场景插画元素、类型徽章配色与网站一致。
- **3.1.4** 所有接口请求失败（网络错误/未登录）有可读的提示，不出现静默失败。

### 3.2 登录页

- **3.2.1** 展示品牌区（标题「{孩子小名}的户外大冒险」，无画像时用通用标题）与「微信一键登录」按钮；点击完成登录并进入计划库。
- **3.2.2** 登录失败（网络异常、code 无效等）展示错误原因与重试入口。

### 3.3 计划库（Tab 1）

- **3.3.1** 顶部 Hero：标题 + 副标题（出行成员 · 城市出发 · 每周末一次，取自用户画像；无画像时显示通用文案）。
- **3.3.2** 非归档方案按月份分组，卡片含：主题场景元素、标题、日期、地点、类型徽章、自驾时长、「妈妈同行」标记。
- **3.3.3** 归档方案归入页面底部「📦 备用计划」区。
- **3.3.4** 顶部展示安全口诀横幅（内容与网站一致的 5 条）。
- **3.3.5** 点击卡片进入方案详情。

### 3.4 方案详情（公共方案，只读）

- **3.4.1** 区块与网站一致：Hero（插画 + 标题 + 徽排行）、🎯 本周目标、💡 爸爸的小抄、🗡️ 小勇士任务（只读展示）、🕐 行程安排（多日方案分天展示）、🎒 本周必带装备（只读展示）、🛡️ 安全要点、📝 回顾问题。 ✅（路线图与出行数据绑定，不在方案详情展示，见 3.6.3）
- **3.4.2** 底部固定操作栏：未加入时显示「加入我的出行」（可选出发日期，默认方案原定日期）；已加入时显示「查看我的出行」并跳转对应出行详情。

### 3.5 我的出行（Tab 2）

- **3.5.1** 出行按出发日期排序分区展示：进行中在前、已完成在后；卡片含方案要点信息与状态标识（已打卡 ✔）。
- **3.5.2** 空状态展示引导文案与「一键加入本赛季计划」按钮（为全部非归档方案创建出行）。
- **3.5.3** 点击进入出行详情。

### 3.6 出行详情（核心页）

- **3.6.1** 内容区块同 3.4.1，但小勇士任务与装备清单**可勾选**；勾选即保存到服务端，保存失败时回滚勾选并提示。
- **3.6.2** 装备区顶部显示进度条与「已准备 N/M 件」；100% 时显示「🎉 全部准备好啦，出发！」。
- **3.6.3** 路线图使用小程序原生地图组件：驾车路线绘制路线折线与起/终点及沿途地标标记；徒步路线绘制路径与带序号的途径点标记；无路线数据时显示占位提示并注明「导航请用高德 App」。
- **3.6.4** 顶部胶囊锚点导航（目标/任务/行程/路线/装备/安全/回顾），点击滚动到对应区块。
- **3.6.5** 有徽章的出行显示「🏁 完成本次冒险（长按 2 秒打卡）」按钮：按住期间显示进度动画，松手取消；打卡成功后按钮变为已完成态（✅ 已完成本次冒险 · 徽章名）。
- **3.6.6** 打卡成功弹出庆祝：展示解锁的活动徽章；若小勇士任务全部勾选，徽章以满星版样式展示；若同时满足里程碑规则，一并展示新解锁的里程碑。
- **3.6.7** 可修改出发日期；可删除该出行（二次确认），删除后返回列表。

### 3.7 我的（Tab 3）

- **3.7.1** 用户卡片：昵称（微信用户默认「微信用户」）与加入时间。
- **3.7.2** 统计条：已冒险 N 次 · 徒步 X km · 露营 N 晚（按已完成出行统计）。
- **3.7.3** 徽章墙：已解锁徽章高亮展示（含里程碑），未解锁显示「？？？」。
- **3.7.4** 家庭画像摘要：出行成员、孩子小名与年龄（按出生年份实时计算）、出行偏好，只读展示；未设置画像时显示占位提示。
- **3.7.5** 退出登录：清除本地登录态并返回登录页。

### 3.8 登录与账号（后端配套）

- **3.8.1** 提供微信小程序登录接口：小程序端提交 `wx.login` 获得的 code，服务端换取 openid 后签发登录态（JWT），首次登录自动创建账号。
- **3.8.2** 同一微信账号（同一 openid）重复登录进入同一账号。
- **3.8.3** 微信登录账号与邮箱密码账号相互独立，互不影响。

## 四、待办清单

- 微信 AppID / Secret 配置到生产环境（个人小程序注册）。
- 真机预览与备案域名配置（request 合法域名）。
- 离线弱网场景的本地缓存（山里信号差，查看类内容可考虑缓存）。
- 分享给家人（小程序卡片分享）。
- 小程序端画像设置：当前微信账号未设画像时 Hero 与「我的」显示兜底文案（画像编辑在网页端 T3）；后续可在小程序内提供简化画像初始化，或支持微信账号与既有账号绑定。
- `web/` 的 OpenAPI 生成类型随新登录接口重新生成（T3/T4 顺带处理）。

## 五、明确不做的（边界）

- 不做方案编辑：小程序中公共方案只读；个性化仅支持出行日期（更多覆盖项留给网页端）。
- 不做实时 GPS 导航：地图为指路参考，导航仍用高德 App。
- 不做微信支付、订阅消息、公众号互通。
- 不做账号合并：微信账号与邮箱账号不打通。
- 不做社交功能（评论、排行、动态）。
- 不做多语言。
