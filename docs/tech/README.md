# 技术文档中心

> 本目录存放项目的**技术文档**：数据契约、模块机制、操作手册。
> 与 PRD / ADR 的分工：**PRD 回答"做什么"**（用户可验收的需求）、**ADR 回答"为什么这么定"**（关键岔路口的取舍，追加式）、**本目录回答"怎么实现的、怎么操作"**（活文档）。

## 维护规则

1. **活文档**：代码改了机制或契约，**同一笔改动里更新对应文档**。每份文档带文档头（版本 · 日期）和文末「修订记录」；与全局规则一致，**版本号与修订记录只在提交时更新**，未提交的改动不动它们。
2. **不重复**：PRD/ADR 引用本目录，不复制内容；本目录也不复述需求理由（理由去 ADR 找）。
3. **实现细节不另起文档**：抽稀容差、重试次数这类随时可调的细节写代码注释，不进本目录。
4. **新领域新文件**：出现新的技术领域（如数据库、新工具链）时新增一份，并在下方索引登记。
5. **隐私红线**：与 docs 全局规则一致——真实个人值一律不出现，只用占位示例。
