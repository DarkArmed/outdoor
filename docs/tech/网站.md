# 网站架构

> 版本：v2.0 ｜ 日期：2026-09-14

React 前端已经接入 FastAPI。`site/` 静态站已退役；运行与旧记录导入见 [操作手册](操作手册.md)。

## 目录与职责

- `web/src/pages/`：首页、方案详情、登录、注册、家庭画像、个人出行管理。
- `web/src/components/`：月份轴、计划卡、详情导航、清单、长按打卡、徽章与足迹抽屉。
- `web/src/svg/`：纯 SVG 场景与地图渲染。`__fixtures__/` 仅保存旧渲染器供回归对比，不属于生产入口。
- `web/src/api/`：axios 客户端与 OpenAPI 生成类型；`hooks/` 用 SWR 加载和刷新数据。
- `backend/`：JWT、画像、公共方案、出行快照及状态持久化。
- `data/`：公共方案、路线、路网与里程碑种子数据；`tools/dump-data.js` 导出为后端初始化输入。

## 路由与数据

登录/注册以外的页面要求登录。首页按月份排列公共方案，归档方案显示在备用区。`?panel=badges|footprint` 控制成就抽屉。

`/plan/:id` 显示方案，已有出行时默认选择最近创建的一次；`?trip=<id>` 精确选择个人出行。显示内容为 snapshot 与 overrides 的顶层合并，创建后公共方案更新不改变已有快照。`/my-trips` 支持创建、改日期和名称、删除；`/profile` 支持新建或编辑家庭画像。

认证恢复期间不渲染私有页面。SWR 缓存按会话隔离，退出后清除 JWT，再登录切换账号。

装备与任务逐项写入后端，保存期间禁用清单，失败提示重试。长按两秒打卡，提前松开、移出、取消、失焦均取消；支持空格和 Enter。任务不必全部完成才能打卡，全部完成时显示满星庆祝。后端在同一事务内保存打卡和徽章，重复打卡复用已有记录。

地图通过 `/api/routes` 和 `/api/network` 加载。没有真实路线时回退示意图；路线文字在插入 SVG 前转义。家庭位置编辑不会自动重新规划路线，当前复用公共路线。

## 旧记录迁移

首次登录自动读取同源浏览器的 `gear:<planId>:<idx>`、`tasks:<planId>:<idx>`、`plans:done`、`badges:unlocked`。原始键保持不变；浏览器保存导入归属，后端保存用户与载荷摘要组成的回执。重试不会重复创建出行，也不会覆盖后来改过的清单。未知计划或无效索引整批拒绝，可在画像页重试或手动导入 JSON。

## 验证

Vitest 覆盖认证、API、页面、迁移转换、成就计算与 SVG 新旧输出。Playwright 使用独立临时 SQLite 与真实 FastAPI，在桌面和移动视口覆盖注册、画像、清单持久化、打卡、徽章、足迹、出行修改和账号隔离。对比记录见 [T3/T4 验证记录](前端验收.md)。
