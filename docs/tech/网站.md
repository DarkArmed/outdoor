# 网站（site/）架构

> 版本：v1.0 ｜ 日期：2026-08-07
> 纯静态、零依赖、离线可用：双击 `site/index.html` 即可打开（file:// 协议，无服务器、无构建、无 CDN）。数据以 `<script>` 加载的 JS 文件注入全局变量，**不用 fetch 读 JSON**（file:// 下会被浏览器拦）。

## 文件结构与数据流

```
site/
├── index.html        # 首页：头图 + 左侧时间轴 + 按月分行卡片 + 备用区 + 安全横幅
├── plan.html         # 详情页：?id=<planId> 驱动，左栏周时间轴 + 右侧分区内容
├── css/style.css     # 全部样式（CSS 变量定义配色，--sun/--grass/--coral 等高饱和色板）
└── js/
    ├── app.js        # 渲染逻辑：renderHome() / renderPlan()
    ├── scenes.js     # 卡通插图：sceneSVG(theme) → 主题场景 SVG
    ├── maps.js       # 路线图：driveMapSVG(plan) / hikeMapSVG(plan) → 卡通地图 SVG
    └── data/
        ├── data-a|b|c.js   # PLANS：计划内容（契约见数据契约.md）
        ├── routes.js       # ROUTES：流水线产物（勿手改）
        ├── network.js      # NETWORK：路网背景（流水线产物，勿手改；缺失时地图自动省略路网层）
        └── profile.js      # PROFILE：配置派生物（sync-profile.js 生成，gitignore；缺失时页面用静态兜底文案）
```

数据流向：`data/*.js` 注入 `PLANS / ROUTES / NETWORK / PROFILE` 全局变量 → `app.js` 读取并拼 HTML → `scenes.js` / `maps.js` 按需提供 SVG 字符串。渲染层只依赖这四个抽象数据源，换数据库时只替换加载层。

## 首页（renderHome）

- **MONTHS 月份表**：当前硬编码在 `app.js`（2026-09/10/11/12 四个月份 + 主题词），按 `id` 前缀把计划分进月行。**已知限制：换赛季需改代码**（站点参数化的候选，暂不做）。
- 左侧时间轴：月份节点（大圆点 + 月份 + 主题词），点击平滑滚动到对应月行（周节点只出现在详情页时间轴）。
- 右侧每月一行，行内卡片横向排列可横滑；`archived: true` 的计划进底部备用区。
- 头图副标题由 PROFILE 生成（孩子小名 + 年龄自动计算 + 城市）；无 profile.js 时保留 HTML 静态兜底文案。

## 详情页（renderPlan）

- 左栏 `.detail-rail`：全赛季周计划时间轴（圆点 + 日期 + 主题缩略图 + 标题），当前周高亮，点击切换 `?id=`。
- 内容分区：目标 / 行程 / 路线 / 装备 / 安全 / 回顾，每区带 `.lazy` 类。
- **胶囊导航 snav**：sticky 横条，滚动时高亮当前区块。
- **懒加载**：IntersectionObserver 观察 `.lazy`，进入视口加可见类（淡入 + 行程条目错峰滑入）。
- **装备勾选**：checkbox 状态写 localStorage（`gear:<planId>:<idx>`），进度条按勾选数更新。
- 多日计划：`dayNames` + 二维 itinerary 按天分组渲染。

## 插图（scenes.js）

- `SC` 调色板 + 一组部件函数（scSun/scCloud/scHills/scRiver/scTent/scDadKid/scCar…）。
- `SCENES` 主题表把部件组合成场景；`sceneSVG(theme)` 输出完整 SVG 字符串。新主题 = SCENES 加一条 + 必要的新部件函数。
- **活动小图**：`ACT_ICONS`（48×48 圆形徽章一套）+ `ACT_MATCH` 关键词表；`actIconSVG(text)` 按行程文字首个命中关键词返回图标，未命中回退笑脸。加新活动类型 = 加图标 + ACT_MATCH 加一行（注意顺序，越具体越靠前）。

## 路线图（maps.js）

- **投影**：`makeProj()` 等距圆柱投影（经度乘 cos(纬度) 修正），Y 轴翻转保持北上。**画布固定宽 800、高在 600~800（比例 4:3 ~ 1:1）内随内容宽高比自适应**（`adaptiveH` 钳制）。内容 bbox 先扩展成与画布同宽高比的**可见地理窗口**，路线画在其中、四周空白由路网/地形铺满——不拉伸真实比例、不迁就极端路线形状。
- `driveMapSVG(plan)` / `hikeMapSVG(plan)` 是调度器：`ROUTES[plan.id]` 存在 → 真实地理图（`realDriveMap` / `realHikeMap`），否则回退卡通示意图（`schematicDriveMap` / `schematicHikeMap`）并在页面注明。
- 真实自驾图元素：路网背景（`networkLayer` 按视野过滤 NETWORK，motorway/trunk/primary 三级灰度，圆角裁剪）、路线折线、路牌（roads）、地标（landmarks）、起终点标记、里程时长徽标、指北针。
- **标签/标点避让**：起终点名称 label 最优先（先于地标放置、就近、注册为障碍）；地标 pin 把「起终点圆 + label」合并为整体障碍，用 `pushOutOfRects` 上下左右四角逃逸整体推挤（避免顺序推挤在多个障碍间振荡）；路名、地标名、徒步点位块均走碰撞避让（`placeLabelAt` / `placeHikeBlock`）。
- 真实徒步图元素：spots（带 act 活动标注 + 顺序编号）、步行路径；`pathSource: 'schematic-link'` 时虚线连接并注明示意。
- 行程时间轴的每个时刻由 `actIconSVG(text)` 自动配活动小图（见上文插图节）。
