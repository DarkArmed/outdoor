# 操作手册（SOP）

> 版本：v1.0 ｜ 日期：2026-08-07
> 常用操作流程，照着打勾即可。涉及字段含义查 [数据契约.md](数据契约.md)。

## SOP-1 新增一周计划

1. 复制 `plans/周计划模板.md` → `plans/2026-MM-DD_活动名.md`，填内容（**必含「本周必带装备」勾选清单**）。
2. 在 `site/js/data/data-x.js` 追加一条 PLANS 数据（字段契约见数据契约.md 第二节；外地目的地记得 `geoCity`）。
3. 跑路线流水线生成路线数据：
   ```bash
   cd tools/route-pipeline
   node pipeline.js 2026-MM-DD    # 只处理新计划
   ```
4. 更新 `00-赛季总览.md` 的计划索引表。
5. 浏览器打开 `site/plan.html?id=2026-MM-DD` 验收：插图主题对、两张路线图是真实地理、装备清单可勾选。

## SOP-2 修改用户配置（config/profile.json）

1. 编辑 `config/profile.json`（真实值永不入库）。
2. 跑同步脚本重新生成网站用配置：
   ```bash
   node tools/sync-profile.js
   ```
3. **改了 `home`**：额外重跑全量流水线（路线起点变了，全部要重算）：
   ```bash
   cd tools/route-pipeline
   node pipeline.js
   ```
4. 刷新网页检查头图文案、自驾起点。

## SOP-3 归档/恢复一个计划

1. PLANS 数据中该计划加 `archived: true`（流水线自动跳过，首页进备用区）。
2. Markdown 文档移入 `plans/备用/`；恢复时反向操作并去掉 `archived`。
3. 更新 `00-赛季总览.md` 索引表。

## SOP-4 重跑路线流水线

```bash
cd tools/route-pipeline
node pipeline.js            # 全量（有缓存，增量快；失败的计划保留旧数据）
node pipeline.js <planId>   # 单个
```

什么时候要重跑：新增计划、改目的地/waypoints、改 home、 routes.js 数据明显错误。

## SOP-5 换电脑/重新克隆后恢复

1. 照 `config/profile.example.json` 抄一份为 `config/profile.json`，填真实值。
2. 照 `tools/route-pipeline/config.example.json` 抄一份为 `config.json`，填高德 Key。
3. 执行 SOP-2 第 2、3 步（生成 profile.js + 重跑流水线）。
4. 浏览器打开 `site/index.html` 验收。

## SOP-6 活动结束后写回顾

在当周计划 Markdown 的「回顾」区补记实际情况（里程/用时/孩子状态/问题教训），作为后续计划迭代依据。
