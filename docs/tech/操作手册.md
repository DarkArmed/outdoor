# 操作手册（SOP）

> 版本：v1.2（草案） ｜ 日期：2026-09-13
> 常用操作流程，照着打勾即可。涉及字段含义查 [数据契约.md](数据契约.md)。
> 后端服务化后（ADR-003）：SOP-7 改为后端 dev 运行方式；本阶段 `site/` 不动，React 前端 T3–T7 暂停。

## SOP-0 一次性准备（高德 Key + 本地配置）

> 要求 Node 18+（内置 fetch）。

1. **申请高德 Web 服务 API Key（免费）**
   - 打开 [lbs.amap.com](https://lbs.amap.com) → 注册/登录 → 控制台 → 应用管理 → 创建应用
   - 添加 Key，服务平台选 **「Web 服务」**
   - 个人开发者免费额度：地理编码、路径规划均为每日数万次，远超本项目用量
2. **配置流水线 Key**
   ```bash
   cd tools/route-pipeline
   cp config.example.json config.json
   ```
   编辑 `config.json`，把 `amapKey` 填成你的 Key（此文件已 gitignore）。
3. **配置用户隐私信息**：照 `config/profile.example.json` 抄一份为 `config/profile.json`，填真实值（gitignore）。家的位置在这里，不在流水线配置里。
4. 想预览效果但暂时没有 Key：跑 `node mock.js` 生成白河湾示例数据（会覆盖 routes.js，之后用 pipeline 重新生成即可）。

## SOP-1 新增一周计划

1. 复制 `plans/周计划模板.md` → `plans/2026-MM-DD_活动名.md`，填内容（**必含「本周必带装备」勾选清单**）。
2. 在 `site/js/data/data-x.js` 追加一条 PLANS 数据（字段契约见数据契约.md 第二节；外地目的地记得 `geoCity`）。
3. 跑路线流水线生成路线数据：
   ```bash
   cd tools/route-pipeline
   node pipeline.js 2026-MM-DD    # 只处理新计划
   ```
4. 更新 `00-赛季总览.md` 的计划索引表。
5. 浏览器打开 `site/plan.html?id=2026-MM-DD` 验收：插图主题对、两张路线图是真实地理、装备清单可勾选。

## SOP-2 修改用户配置（config/profile.json）

1. 编辑 `config/profile.json`（真实值永不入库）。
2. 跑同步脚本重新生成网站用配置：
   ```bash
   node tools/sync-profile.js
   ```
3. **改了 `home`**：额外重跑全量流水线（路线起点变了，全部要重算）：
   ```bash
   cd tools/route-pipeline
   node pipeline.js
   ```
4. 刷新网页检查头图文案、自驾起点。

## SOP-3 归档/恢复一个计划

1. PLANS 数据中该计划加 `archived: true`（流水线自动跳过，首页进备用区）。
2. Markdown 文档移入 `plans/备用/`；恢复时反向操作并去掉 `archived`。
3. 更新 `00-赛季总览.md` 索引表。

## SOP-4 重跑路线流水线

```bash
cd tools/route-pipeline
node pipeline.js            # 全量（有缓存，增量快；失败的计划保留旧数据）
node pipeline.js <planId>   # 单个
```

什么时候要重跑：新增计划、改目的地/waypoints、改 home、 routes.js 数据明显错误。

## SOP-5 换电脑/重新克隆后恢复

执行 SOP-0（Key + 配置），然后执行 SOP-2 第 2、3 步（生成 profile.js + 重跑流水线），浏览器打开 `site/index.html` 验收。

## SOP-6 活动结束后写回顾

在当周计划 Markdown 的「回顾」区补记实际情况（里程/用时/孩子状态/问题教训），作为后续计划迭代依据。

## SOP-7 运行后端服务（dev 模式，后端服务化后）

> 后端已升级为 FastAPI + PostgreSQL/SQLite 服务（ADR-003），本阶段 `site/` 不动，React 前端暂不接入。

1. **准备配置**：
   ```bash
   cd backend
   cp .env.example .env
   ```
   编辑 `.env`，本地开发可设 `DATABASE_URL=sqlite:///./outdoor.db`；生产用 PostgreSQL。

2. **安装依赖**：
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. **数据库迁移**：
   ```bash
   alembic upgrade head
   ```

4. **导入数据**（从现有 `site/js/data/*.js` + `config/profile.json`）：
   ```bash
   python -m app.seed
   ```

5. **启动服务**：
   ```bash
   uvicorn app.main:app --reload
   ```
   访问 http://localhost:8000/docs 查看 API 文档。

## SOP-8 新增后端消费方（小程序 / 移动端 / 未来 React 前端）

1. 消费方通过 `/api/auth/register` 和 `/api/auth/login` 获取 JWT。
2. 后续请求带 `Authorization: Bearer <token>`。
3. 公共方案：`GET /api/plans`。
4. 创建个人出行计划：`POST /api/trips`（`plan_id` + `planned_date` + `overrides`）。
5. 读取个人出行计划详情：`GET /api/trips/{id}`（返回 `snapshot` + `overrides` 合并后的 `content`）。
6. 状态同步：`GET/PUT /api/trips/{id}/gear`、`GET/PUT /api/trips/{id}/tasks`。
7. 打卡：`POST /api/trips/{id}/checkin`。

> 旧 `site/` 静态站（双击 index.html）过渡期仍可用，React 前端功能对齐后退役。
