# ADR-004 · 微信小程序客户端：原生小程序 + code2session 登录

> 编号：ADR-004 ｜ 日期：2026-10-01 ｜ 状态：**已确认**
> 关联需求：PRD-005（小程序客户端）；PRD-004（多用户与方案/出行计划解耦，JWT 供小程序复用）

## 背景

ADR-003 选择 JWT 认证时就明确「便于未来小程序通过同一接口认证」。现在启动第一个移动客户端（PRD-005）。需要决定：小程序技术栈、微信登录与现有 User 模型的整合方式、登录态策略、地图方案、以及无 AppID 时的本地开发方式。

## 决策

**客户端用原生微信小程序（WXML/WXSS/JS，无构建链）；登录用 `wx.login` code 换取 openid、落库后复用既有 JWT；地图用原生 `<map>` 组件直接渲染后端 GCJ-02 路线数据。**

- **原生小程序，不引入跨端框架**：客户端只有微信一个目标平台，页面约 6 个，体量小；原生方案零构建、零 npm 依赖、调试链路最短，与仓库 `site/` 零依赖的风格一致。跨端框架（Taro/uni-app）带来的构建链与升级成本在单平台场景没有回报。
- **登录整合：User 表新增两列，不放宽既有约束**：
  - `wechat_openid`（String(64)，唯一、可空、索引）绑定微信身份；
  - `nickname`（String(64)，可空）供展示（默认「微信用户」）。
  - 微信用户的 `email` 写入占位值 `wx_<openid>@wechat.local`，`hashed_password` 写入随机不可用散列。既有 `email`/`hashed_password` 的 NOT NULL 约束不动，迁移只增列、可回滚；邮箱账号体系零影响。
  - 新端点 `POST /api/auth/wechat/miniapp`：入参 `{code, nickname?}`，出参 `{access_token, token_type, is_new_user, user}`。服务端用 httpx 调微信 `jscode2session`；`session_key` **只留在服务端、绝不下发**。
- **登录态复用 JWT，不引入 refresh token**：有效期沿用 7 天默认。过期后小程序用 `wx.login` 无感换 code 静默重登（微信生态内无需用户操作），体验上等效长登录，省掉 refresh token 的签发/存储/轮换复杂度。
- **地图用原生 `<map>` 组件**：后端路线流水线产出的坐标本就是 GCJ-02（ADR-001），与微信地图组件坐标系天然一致，无需任何转换；驾车 polyline、地标 markers、徒步途径点直接渲染。不内嵌 web-view 地图（需业务域名配置，体验割裂）。
- **本地开发 mock 模式**：后端未配置 AppID/Secret 且 `debug=true` 时，code2session 返回确定性 mock openid（`dev_<code 截断>`），供本地与测试使用；配置了真实 AppID/Secret 后该分支永不生效。测试通过依赖覆盖替身 code2session HTTP 调用，不依赖外网。
- **状态同步：乐观更新 + 单项批量写**：装备/任务勾选先更新界面，再用既有批量接口（PUT 数组）提交单项，失败回滚。不新增单项 toggle 端点，后端改动保持最小。

## 放弃的备选方案

| 方案 | 放弃原因 |
|---|---|
| Taro / uni-app 跨端框架 | 单平台无收益，引入构建链与升级负担 |
| 放宽 `email`/`hashed_password` 为可空 | 污染既有约束语义，迁移影响面大于新增占位值 |
| 引入 refresh token | 7 天 token + 微信静默重登已等效，复杂度不值 |
| 下发 `session_key` 到前端自管登录态 | 安全红线（可解密用户数据），且重复造登录态轮子 |
| web-view 内嵌 H5 地图 | 需配置业务域名，与原生体验割裂 |
| 新增 gear/task 单项 toggle 端点 | 既有批量接口提交单项数组即可满足，后端零额外改动 |
| unionid 多端打通 | 当前只有一个小程序，无打通对象 |

## 风险与边界

- **mock 模式安全**：仅在「未配置 AppID 且 debug=true」时生效；生产部署必须配置真实 AppID/Secret 且 debug=false，此时未配置走 503 报错而非放行。
- **AppID 归属**：小程序需要注册个人小程序账号获取 AppID/Secret；仓库中只存占位符，真实值进 gitignore 的 `.env`。
- **隐私红线不变**：画像信息仍只存运行期数据库，小程序端不落任何敏感数据到代码或文档。
- **真机域名**：正式发布需配置 request 合法域名（https）；本地开发在微信开发者工具勾选「不校验合法域名」。
