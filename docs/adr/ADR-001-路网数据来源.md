# ADR-001 · 路网背景数据来源：OpenStreetMap + GCJ-02 转换

> 编号：ADR-001 ｜ 日期：2026-08-07 ｜ 状态：**已确认**
> 关联需求：PRD-001 §2.3.5（路线图渲染当地主要路网）

## 背景

自驾路线图需要在路线下方渲染当地主要路网（二环–五环、G6/G7 等）作为地理参照。路线数据来自高德（GCJ-02 坐标），路网数据需要一个**有区域路网矢量接口**的来源。

## 决策

**路网数据用 OpenStreetMap（Overpass API），坐标经 WGS-84 → GCJ-02 转换后与高德路线对齐。**

- 抓取方式：流水线按固定区域（北京及周边，含坝上）查询 `highway ∈ motorway/trunk/primary` 的 way 几何，抽稀后写入共享的 `site/js/data/network.js`，全部计划复用一份。
- 坐标转换：流水线内实现公开的 GCJ-02 偏移算法，误差 <10m，本场景（卡通示意地图）可忽略。
- 抓取失败处理：保留已有 network.js，不阻断路线生成。

## 放弃的备选方案

| 方案 | 放弃原因 |
|---|---|
| 高德 Web 服务 API | 没有"区域内路网"矢量接口 |
| 高德静态图 API | 输出图片而非矢量，无法卡通化渲染、无法与路线分层 |
| 高德 JS API 在线瓦片 | 违背网站离线（file://）约束；且风格不可控 |
| 手工绘制路网 | 不可维护，违背"真实地理"原则 |

## 风险与边界

- OSM 中国数据为社区维护，个别小路可能缺失——但高速/环路/主干道覆盖完整，满足需求。
- Overpass 为境外公共服务，可能偶发慢/不可用：已内置多镜像重试，且失败不阻断主流程。
- 路网为**快照**（随流水线运行更新），不追求实时路况。
