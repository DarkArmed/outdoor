# 备用 · 灵山银河露营（进阶）

> 状态：备用·**进阶**。北京最高峰（2303m）顶级暗夜，银河核心带清晰可见。**不建议作为首次观星露营**：山顶夜间 0–5°C、大风常态、无补给无退路，需要完整四季装备 + 至少 3 次露营经验后再考虑。

## 基本信息

- **地点**：门头沟·灵山自然风景区（车程约 2.5 小时）
- **类型**：C 露营过夜（观星主题，高阶）
- **目标**：顶级暗夜银河 + 日出云海（看运气）

## 要点

- **大风/雷雨预警直接改期，不赌天气**
- 保守玩法：山腰江水河村住宿，晚上开车上顶看 2 小时再下来——体验 90%、风险 10%
- 周六中午出发 → 山腰确认天气风力 → 上顶搭营（帐篷口背风、打满地钉风绳）→ 19:00 银河核心带 → 20:30 睡（睡袋温标 ≤-5°C）

## 本周必带装备

- [ ] 四季帐（抗风）⭐ / 睡袋温标 ≤-5°C ⭐ / 加厚防潮垫 ⭐
- [ ] 羽绒服+抓绒+冲锋衣全套 ⭐ / 保温毯（应急）
- [ ] 头灯（红光）+备用电池 / 炉头+锅具 / 充电宝 ×2
- [ ] 天文望远镜（先评估携带重量）/ 急救包、能量零食（加倍）、垃圾袋

## 安全

每半小时查孩子手脚温度，失温迹象立即下撤 / 车停附近做应急避难所 / 提前告知亲友行程+预计返程时间
