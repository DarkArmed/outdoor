# 备用 · 大吉祥村暗夜露营

> 状态：备用。波特尔 3 级暗夜（接近灵山级别），但村里有农场木屋做退路——孩子冷了随时进屋，带娃观星的「暗夜与便利平衡点」。流星雨高峰期（8 月英仙座/12 月双子座）首选这里。

## 基本信息

- **地点**：延庆·大吉祥村（车程约 2 小时，导航限定延庆）
- **类型**：C 露营过夜（观星主题）
- **目标**：暗夜银河 + 流星雨观测，木屋保底

## 要点

- 提前订营位或木屋（流星雨周末紧张）
- 周六下午出发 → 搭营或入住 → 19:30 观星 → 孩子 21:00 睡；周日自然醒收营返程
- 看流星雨：仰卧防潮垫肉眼扫全天空，比望远镜好用（望远镜视场太小）

## 本周必带装备

- [ ] 帐篷（或订木屋）⭐ / 睡袋 ×3（温标 ≤0°C）⭐ / 充气防潮垫 ×3
- [ ] 头灯（红光模式）⭐ / 炉头+锅具+餐具 / 保温水壶
- [ ] 薄羽绒+长裤 / 天文望远镜+镜头布（流星雨夜可不带）
- [ ] 急救包、能量零食、垃圾袋、充电宝

## 安全

夜间保暖第一位，孩子冷了立即进屋 / 红光手电 / 不熬夜硬撑 / 离线地图 / 防火
