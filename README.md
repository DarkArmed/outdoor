# 户外亲子计划 · 北京

> 每个周末一次的亲子户外活动规划。**爸爸 + 7 岁男孩**，自驾（单程可 3 小时），北京出发。
> 原则：**安全第一 · 循序渐进 · 让孩子爱上自然**。
> 本仓库是一个长期迭代的规划项目，按周生成计划文档，后续可升级为图文版 HTML。

## 使用方式

1. **出发前**：打开当周计划文档，核对「本周必带装备」逐项打勾。
2. **回来后**：在计划文档「回顾」区记录实际情况（走了多远、孩子反应、天气、经验教训）。
3. **迭代**：随时让 Claude 生成新一周计划、更新装备台账、按回顾优化后续方案。
